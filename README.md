# Tips-for-Coding
The goal of this repo is to strictly point out and explain the difficulties some people may experience when coding and provide recommendations in order to improve general programming experience. I decided to make this because there are some problems that normally aren't addressed even in commonly used programming guides, and I want to share the solutions to these discrete problems. I will do this by going through coding problems myself, and identifying the possible mistakes or problems that can happen and provide recommendations in order to avoid it.
